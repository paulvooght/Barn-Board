## How it was built (one-off bootstrap)
```bash
# 1. Crop the raw photo to the board (done in Python/Pillow → Yonder_Set_01_V1.jpg)
# 2. Detect holds (expanded palette + watershed split; reads the cropped image directly)
python3 scripts/detect_holds.py --image board-assets/yonder/Yonder_Set_01_V1.jpg \
        --output board-assets/yonder/holds_detected.json
# 3. Create the wall + seed holds + region (dry-run first), then publish the image
node --env-file=.env.local scripts/seed_yonder.mjs --commit          # twin of 006_yonder_board.sql
python3 scripts/publish_board_image.py Yonder_Set_01_V1 --board yonder
```
